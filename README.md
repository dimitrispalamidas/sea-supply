# Sea Supply

Supply ordering app for **seafarers**: crew members place orders (personal or professional items), the captain approves, and the order is sent to shore for delivery.

**Live:** [sea-supply.vercel.app](https://sea-supply.vercel.app) *(work in progress)*

## Stack

Next.js · React · Tailwind CSS

## Τοπική εκτέλεση

```bash
npm install
npm run dev
```
